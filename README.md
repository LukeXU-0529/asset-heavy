# Asset Heavy · 产业产能地图

同一个 GitHub Pages 入口按产业链切换。默认打开 PCB，`?chain=fab` 直达 Fab 与封测，`?chain=fab-overseas` 直达 Fab · 海外的世界地图，可分别查看晶圆制造和海外封测基地。

- 各图谱都按公司 → 城市整体 → 基地／项目组织，提供地图、年度工作台、项目时间线、基地清单与来源口径。
- PCB 和 Fab 的发布文件分别为 `pcb.html` 和 `fab.html`，各自从同目录的 `snapshot.*.json` 载入基地、公开资料和城市口径。PCB 图谱可筛选电子布、铜箔、树脂与 PCB 辅料。辅料可按成像与阻焊、电镀与表面处理、钻孔与成型筛选。全球视图可查看境外厂址。
- PCB 和 Fab 的个人情景分别保存在本浏览器。请用各自页面中的 JSON 备份转移数据。城市研究值、集团披露和单项目口径分别保存。
- 新增产业链时，向 `index.html` 中的 `chains` 列表添加对应页面。请从仓库根目录启动静态 HTTP 服务进行本地预览。
